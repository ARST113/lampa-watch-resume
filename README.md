# Lampa Watch Resume

Плагин добавляет на карточку сериала одну кнопку **«Продолжить · SxxExx»**.
Она выбирает online или torrent по последнему подтверждённому просмотру,
заново строит актуальный плейлист и сразу запускает нужную серию с сохранённой позиции.

## Установка

В Lampa откройте **Настройки → Расширения → Добавить плагин** и укажите:

```text
https://arst113.github.io/lampa-watch-resume/watch_resume.js
```

## Возможности

- одна кнопка продолжения прямо на карточке сериала;
- online и torrent через общий сценарий, с выбором последнего режима;
- полный плейлист всех доступных серий сезона или всех видеофайлов раздачи;
- внутренний плеер и Just Player+;
- синхронизация рецептов и позиций через Lampac Sync;
- поддержка TorrServer `TrackTimecode`;
- при просмотре 90% и более выбирается следующая доступная серия;
- прямой запуск через актуальный `lampac.fun/online.js`, даже без
  необязательного моста `LampacOnlineResume`;
- при ошибке показывается уведомление, а пользователь не остаётся в списке
  online-источника или торрент-файлов.

Плагин не сохраняет готовые ссылки воспроизведения, ссылки качества,
субтитров, прокси или временные токены. В истории остаются только данные,
необходимые для повторного построения актуальной ссылки.

## Требования

- Lampa Android 98+ для полного возврата позиции и плейлиста из Just Player+;
- Just Player+ для внешнего воспроизведения;
- установленный Lampac Online; мост `LampacOnlineResume` необязателен;
- актуальный TorrServer; `TrackTimecode` используется только при включённой
  одноимённой настройке Lampa/TorrServer.

Nova Skin не требуется и не используется.

## Дополнительный плагин: ARX Player Tools 0.6.1

[**Установить JavaScript-плагин**](https://arst113.github.io/lampa-watch-resume/arx_player_tools.js) · [Исходники](arx_player_tools.js) · [Подробная документация](ARX_PLAYER_TOOLS.md)

Для внутреннего HTML5-плеера Lampa: пропуск заставок, рекапов и титров, ручные границы, отмена пропуска, скорости, таймер сна, дополнительная информация и субтитры. Управление ТВ через штатные селекторы, `hover:enter`, пульт и полупрозрачные элементы интерфейса Lampa.

- Готовые субтитры OpenSubtitles/Stremio ищутся и скачиваются **на стороне JavaScript Lampa**, без ИИ-сервера и собственного VPS.
- **ИИ-перевод выключен по умолчанию**. При желании включите отдельный переключатель «Использовать ИИ». Только тогда доступны выбор провайдера и поля ключа.
- Провайдеры ИИ: **OpenRouter** (Auto + Free) или **произвольный OpenAI-совместимый HTTPS API** (адрес, модель, необязательный ключ). Отдельного фиксированного профиля DeepSeek нет: его API можно указать как совместимый сервис.
- После автоматического пропуска кнопка возврата исчезает через **3 секунды**, после ручного — через **5 секунд**.
- Данные для прямого ИИ-вызова и ключи хранятся на клиенте; других плагинов и синхронизации это не изолирует. Не используйте мастер-ключ без лимита расходов.

Основной плагин **watch_resume.js** в этом репозитории не менялся.

Текстовая кнопка пропуска показывает круговой отсчёт и исчезает на точной границе сегмента, обновление прогресса работает только во время показа.
