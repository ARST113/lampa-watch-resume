# Lampa Watch Resume

Плагин добавляет на карточку сериала одну кнопку **«Продолжить · SxxExx»**.
Она выбирает online или torrent по последнему подтверждённому просмотру,
заново строит актуальный плейлист и сразу запускает нужную серию с сохранённой позиции.

## Установка

В Lampa откройте **Настройки → Расширения → Добавить плагин** и укажите:

```text
https://arst113.github.io/lampa-watch-resume/watch_resume.js
```

## Возможности

- одна кнопка продолжения прямо на карточке сериала;
- online и torrent через общий сценарий, с выбором последнего режима;
- полный плейлист всех доступных серий сезона или всех видеофайлов раздачи;
- внутренний плеер и Just Player+;
- синхронизация рецептов и позиций через Lampac Sync;
- поддержка TorrServer `TrackTimecode`;
- при просмотре 90% и более выбирается следующая доступная серия;
- прямой запуск через актуальный `lampac.fun/online.js`, даже без
  необязательного моста `LampacOnlineResume`;
- при ошибке показывается уведомление, а пользователь не остаётся в списке
  online-источника или торрент-файлов.

Плагин не сохраняет готовые ссылки воспроизведения, ссылки качества,
субтитров, прокси или временные токены. В истории остаются только данные,
необходимые для повторного построения актуальной ссылки.

## Требования

- Lampa Android 98+ для полного возврата позиции и плейлиста из Just Player+;
- Just Player+ для внешнего воспроизведения;
- установленный Lampac Online; мост `LampacOnlineResume` необязателен;
- актуальный TorrServer; `TrackTimecode` используется только при включённой
  одноимённой настройке Lampa/TorrServer.

Nova Skin не требуется и не используется.

## Дополнительный независимый плагин: ARX Player Tools

Разрабатывается отдельный JS-плагин для **внутреннего плеера Lampa**: пропуск заставок, рекапов и титров (SkipDB, IntroDB, TheIntroDB, AniSkip), локальное редактирование меток, отмена пропуска, таймер сна, скорость воспроизведения, дополнительные субтитры HTML5 и совместимость с OpenSubtitles RU.

**Установка в Lampa:** https://arst113.github.io/lampa-watch-resume/arx_player_tools.js

**[Исходный код](arx_player_tools.js)** · **[Возможности, ограничения и проверка](ARX_PLAYER_TOOLS.md)**

Версия 0.4.0 экспериментальная; устройство Android TV ещё не проверено. Оригинальный плагин продолжения просмотра `watch_resume.js` не изменён. Если установлен сторонний Lampa Auto Skip, ARX отключает собственные пропуски во избежание конфликтов.

Поддержка управления на ТВ: кнопка ARX находится в штатной панели плеера и использует события `hover:enter`, `Controller` и стрелки пульта. Автоматизированные тесты имитируют пульт; проверка на физическом телевизоре остаётся обязательной.

**ARX Player Tools 0.4.1:** без плавающей кнопки, собственный OpenSubtitles/Stremio-поиск и ИИ-перевод через [ARX subtitles backend](arx-subtitles-server/README.md). Для ИИ необходимо развернуть backend и указать его HTTPS-URL и токен в настройках Lampa. Старый OpenSubtitles RU по умолчанию отключается во избежание конфликтов, без удаления его данных.

В версии **0.4.1** поиск и загрузка готовых субтитров всегда выполняются напрямую из JS Lampa; собственный backend нужен только для ИИ и необязательного резервного прокси при недоступности OpenSubtitles с ТВ.
