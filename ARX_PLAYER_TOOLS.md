# ARX Player Tools 0.5.0 для Lampa

Экспериментальный JS-плагин для внутреннего HTML5-видеоплеера Lampa. Не заменяет ARX TPlayer и не меняет встроенные видеодекодеры.

## Установка

Lampa → Настройки → Расширения → Добавить плагин:

https://arst113.github.io/lampa-watch-resume/arx_player_tools.js

Код: [arx_player_tools.js](arx_player_tools.js). Настройки → ARX Player Tools. При просмотре кнопка **ARX** открывает панель управления.

## Что реализовано

### Пропуск сегментов
- SkipDB (IMDb): заставки, рекапы, титры, анонсы; проверка confidence, match и продолжительности.
- IntroDB (IMDb): получение сегментов для сериалов и фильмов.
- TheIntroDB (TMDB): заставки, рекапы и титры по сезону и серии.
- AniSkip (MyAnimeList): опенинги, эндинги и рекапы аниме; проверка продолжительности версии.
- IntroHater: экспериментальный дополнительный источник, выключен по умолчанию.
- Обработка сегментов, переданных запускающим источником Lampa, с приоритетом над удалёнными базами.
- Согласование временных интервалов нескольких независимых баз; один слабый результат требует ручного пропуска.
- Ручное создание границ заставок/рекапов/титров/анонсов/рекламы/послетитровых сцен и удаление своих отметок.
- Автоматическая перемотка только для подтверждённых сегментов, отключена по умолчанию; запрещена для рекламы, превью, сцен после титров.
- Кнопка пропуска с временем до конца сегмента, отмена перемотки в течение 10 секунд, опциональная красная кнопка пульта.
- Цветные отметки на прогресс-баре, когда разметка плеера позволяет это без вмешательства в штатное управление.
- Подсказки по названиям HTML5-глав и по длинным паузам между текстовыми субтитрами: только ручной пропуск, эвристика по субтитрам выключена по умолчанию.

### Функции воспроизведения
- Всплывающее меню ARX: +/- перемотка, скорость 0.75×–2×, управление автопропуском, таймеры, локальные отметки.
- Таймер остановки 15, 30, 45, 60, 90 минут при старте; дополнительные кнопки +15/+30 минут.
- Опциональное плавное снижение громкости в течение последних 30 секунд с восстановлением оригинального уровня.
- Вывод оставшегося времени, предполагаемого времени окончания, скорости, разрешения и буфера.
- Максимум 75 локально кешированных записей, TTL 24 часа, с разделением серий и длительностей.
- Не изменяет историю file_view, sync_view, TorrServer или плагин watch_resume.js.

### Субтитры
- Можно включить необязательную загрузку [OpenSubtitles RU](https://github.com/m3dfatboi/lampa-opensubtitles-ru) при запуске Lampa; если плагин уже указан в списке расширений, второй экземпляр загрузчиком не создаётся.
- Экспериментальная вторая строка субтитров с собственным языком, смещением времени и положением. Работает исключительно с HTML5 TextTrack, которые доступны видеодвижку; встроенные в MKV дорожки вне HTML5 API не появятся от установки JS-плагина.
- Поддерживаемые настройки второго языка: ru, en, es, de, fr; смещение -5/-2/-1/0/+1/+2/+5 секунд.

## Ручная установка границ

1. При просмотре нажать ARX и выбрать тип сегмента.
2. На реальном начале нажать **Отметить начало**.
3. На конце нажать **Сохранить конец**.
4. Метка сохранится локально для этого фильма или серии, с учётом длительности файла; в случае существенного расхождения с онлайн-базами ручное исправление останется приоритетным.
5. Для удаления нажать **Удалить свои метки этого типа**.

### AniSkip ID

При наличии MAL ID в метаданных Lampa он используется автоматически. В остальных случаях в панели ARX для сериала предусмотрено поле MyAnimeList ID: введённое числовое значение привязывается к IMDb/TMDB идентификатору и сохраняется для последующих серий.

## Ограничения и безопасность

Автопропуск по умолчанию выключен: сперва проверьте 2–3 серии одной версии релиза. Неоднозначные или несовпадающие по длительности сегменты не подходят для автоматического пропуска. Указанные в главах или выведенные из пауз субтитров интервалы только предлагаются для ручного подтверждения.

Только внутренняя Lampa управляет HTML5 video.currentTime. Внешний ARX TPlayer, Just+, VLC, mpv, нативные Android-субтитры, аппаратный HDMI passthrough, Dolby Vision и аппаратное декодирование обычным JS расширением не управляются. CORS, отключённые внешние API, отсутствие диапазона seekable, старые WebView и TV-пульты могут ограничивать функции. Если включён сторонний lampa-auto-skip, собственный механизм пропуска ARX отключается.

По сети передаются только публичные IMDb/TMDB/MAL ID, номер серии и продолжительность. Пароли, TorrServer URL, торрент-хеши, URL воспроизведения и историю просмотра плагин не передаёт внешним базам. Уважайте лицензии сервисов, включая ODbL и условия SkipDB.

## Совместимость с пультом телевизора (0.3.1)

Реализация сверена с `ARST113/lampa-source` (модули `src/core/controller.js`, `src/core/keypad.js`, `src/interaction/player/skip.js`, `src/interaction/player/panel.js`).

- В штатную панель `.player-panel__right` добавлена кнопка `ARX` с классом `.selector` и событием `hover:enter`. Если правой секции нет, используются запасные секции панели.
- Через `Controller.add('arx_tools_menu', ...)` регистрируется отдельный контроллер: `Controller.collectionSet`, `Controller.collectionFocus`, перемещение стрелками `Navigator.move`, `Controller.toggle` и возврат в предыдущий контроллер.
- Когда ARX находит сегмент во внутреннем видеоплеере, отдельный контроллер `arx_tools_skip` фокусирует кнопку пропуска; `hover:enter` вызывает seek. Штатный `player_skip` Lampa имеет приоритет, а сегменты, уже переданные Lampa, дополнительно не обрабатываются ARX при наличии родного Skip UI.
- События браузера `click` сохранены для мыши/тача; повторное срабатывание `click` → `hover:enter` подавляется.
- Back/Return (Esc, Samsung 10009, LG 461, Backspace, Orsay 88) закрывает ARX-меню, не закрывая видео. Остальные направления, Enter/OK обрабатывает контроллер Lampa.

**Автоматические проверки:** 34 теста, включая программную имитацию Lampa Controller, hover:enter, стрелок, Back, пропуска OK и взаимодействия со штатным player_skip. [Лог GitHub Actions](https://github.com/ARST113/lampa-watch-resume/actions/runs/38514509166).

**Ограничение тестов:** Chromium/Node с имитацией контроллера не воспроизводит полностью Android TV WebView, Samsung Tizen или LG WebOS и не является подтверждением работоспособности на физическом ТВ. Для окончательной приёмки необходимо проверить в реальном приложении: стрелка вниз → штатная панель → ARX → OK → навигация по меню → Back → переход к заставке → OK → отмена пропуска; затем повторить на Samsung/LG отдельно.


## Субтитры и ИИ в версии 0.5.0

Плавающая кнопка ARX удалена. Меню находится в штатной панели видеоплеера с управлением selector, hover:enter, Controller и стрелками пульта.

### Поиск готовых субтитров

ARX из JavaScript Lampa напрямую обращается к OpenSubtitles v3 и REST OpenSubtitles, выбирает дорожку, скачивает SRT с Stremio CDN, разбирает временные метки и показывает текст. **Свой сервер ARX не требуется**.

Если оба публичных сервиса недоступны (например, из-за CORS) и пользователь указал необязательный адрес subtitle_api, можно выполнить резервный запрос через него. В обычных условиях он не используется.

### Прямой ИИ-перевод без backend

ARX 0.5.0 отправляет пакеты субтитров по HTTPS непосредственно к выбранному провайдеру:

- DeepSeek — https://api.deepseek.com/v1/chat/completions, модель по умолчанию deepseek-chat.
- OpenRouter — https://openrouter.ai/api/v1/chat/completions, модель по умолчанию google/gemini-2.5-flash.

В настройках доступны ИИ-провайдер, модели и отдельные поля для ключей DeepSeek и OpenRouter.

Сценарий: в плеере открыть ARX, выбрать «Английские для ИИ», нужную дорожку, затем «ИИ-перевод на русский». Текст делится на пакеты до 35 реплик / 3200 символов; каждый ответ обязан иметь исходное количество строк. Таймкоды сохраняются; перевод можно остановить. При ошибках исходная дорожка остаётся неизменной.

**Для ИИ не нужен ни URL VPS, ни запущенный ARX-сервер, ни клиентский токен старого backend.** Ранее созданная папка arx-subtitles-server остаётся в репозитории как необязательный самостоятельный сервис, но плагин 0.5.0 не обращается к нему для перевода.

### Безопасность ключей

Прямое подключение хранит API-ключ в Lampa.Storage на устройстве. Он потенциально доступен другим JS-расширениям, локальному отладчику и механизмам синхронизации настроек. Маскировка поля в интерфейсе предотвращает случайный показ ключа на экране, но **не шифрует его**.

Используйте отдельный ограниченный ключ и лимит расходов. Не публикуйте ключ в GitHub, не используйте общий ключ на общедоступных устройствах. Для публичного распространения безопаснее серверная авторизация.

### Проверки

- Ошибка входа в настройки из-за отсутствующего строкового поля input.values исправлена.
- Автоматические тесты проверяют запросы к DeepSeek/OpenRouter, структуру ответов, пакетную обработку, сохранение таймкодов и независимость от backend.
- CORS preflight для браузерных источников https://lampa.mx и https://lampac.fun разрешён обоими провайдерами, включая POST с Authorization и Content-Type. См. GitHub Actions ARX direct AI browser CORS diagnostics.
- Реальные платные вызовы ИИ и работа на физическом Android TV ещё требуют проверки с пользовательским ключом.

Расходы DeepSeek/OpenRouter тарифицируются провайдером отдельно. Перевод фильма может выполнить десятки последовательных запросов.
