# ARX Player Tools 0.6.0 для Lampa

Независимое JavaScript-расширение **внутреннего HTML5-плеера Lampa**. Не заменяет ARX TPlayer и не меняет системные декодеры Android TV/Tizen/WebOS.

## Установка

В Lampa: **Настройки → Расширения → Добавить плагин**:

```text
https://arst113.github.io/lampa-watch-resume/arx_player_tools.js
```

После обновления полностью перезапустите Lampa. Меню **ARX** находится в штатной панели управления видеоплеера, а при доступном сегменте появляется полупрозрачная капсула с кнопкой «Пропустить: Титры (01:42)» (или соответствующим типом), меню и возможностью отмены.

## Пропуск заставок

- Источники: SkipDB, IntroDB, TheIntroDB, AniSkip (MyAnimeList); IntroHater — экспериментально.
- Интро, рекапы, титры, превью, реклама и послетитровые сцены; типы отключаются отдельно.
- Ручное создание, корректировка и удаление своих границ с привязкой к эпизоду и длительности файла.
- Согласование времени из нескольких баз; автопропуск работает **только для подтверждённых меток** и выключен по умолчанию.
- Кнопка пропуска сохраняет стиль стеклянной капсулы Lampa. Надпись «· проверить» убрана; внутренняя достоверность по-прежнему учитывается.
- После автопропуска кнопка отмены показывается **3 секунды**; после ручного — **5 секунд**. При выходе из плеера она скрывается.
- Управление ТВ через `selector`, `hover:enter`, `Controller`, стрелки и OK. Красная кнопка пульта опциональна.

## Готовые субтитры — без ИИ

Готовые русские или английские дорожки ищутся и скачиваются **из JavaScript Lampa**, без собственного VPS и без API-ключей:

1. Получение IMDb ID карточки (при необходимости через TMDB).
2. Поиск через OpenSubtitles v3 и REST OpenSubtitles.
3. Выбор результата, скачивание SRT через Stremio, разбор таймкодов.
4. Отображение текста поверх видео; ручное отключение.

При сетевых блокировках/CORS можно задать **необязательный резервный прокси субтитров** (выключен по умолчанию). Этот прокси не является ИИ-сервисом и не нужен для нормальной работы прямого поиска.

Также реализованы экспериментальные вторые HTML5-субтитры с настройками языка, смещения и вертикального положения. Встроенные дорожки MKV, недоступные через HTML5 TextTrack, не становятся доступными от установки JS-плагина.

## ИИ-перевод — только по согласию пользователя

Переключатель **«Использовать ИИ для перевода субтитров»** по умолчанию выключен. Пока он выключен:

- Настройки провайдера, модели и API-ключа скрыты.
- Кнопки загрузки английских субтитров *для ИИ* и запуска ИИ-перевода скрыты.
- Запросы к ИИ не отправляются, даже если ключ уже сохранён. Обычный поиск готовых субтитров работает как прежде.

При включении доступны два варианта провайдера.

### OpenRouter

Адрес API предустановлен: `https://openrouter.ai/api/v1/chat/completions`. Требуется личный OpenRouter API-ключ. Режимы:

| Auto | Free | Выбираемая модель |
|---|---|---|
| Вкл | Вкл | `openrouter/free` — бесплатный маршрутизатор |
| Вкл | Выкл | `openrouter/auto` — маршрутизатор, возможна тарификация |
| Выкл | Вкл | Только явный `:free` или `openrouter/free` |
| Выкл | Выкл | Любая ручная модель OpenRouter |

Оба переключателя Auto/Free включены по умолчанию. Free Router ограничен квотами и доступностью моделей; платные вызовы зависят от настроек OpenRouter.

### Другой OpenAI-совместимый API

Выберите «Другой OpenAI-совместимый API» и укажите:

- **HTTPS-адрес сервиса:** например, `https://api.example.org/v1` или полный `https://api.example.org/v1/chat/completions`.
- **ID модели:** произвольное имя модели в формате OpenAI Chat Completions.
- **API-ключ:** если сервис требует авторизацию. Локально размещённый HTTPS-сервис без проверки ключа также поддерживается.

Можно подключить DeepSeek, собственный сервер с vLLM, LM Studio за HTTPS-прокси и другие совместимые Chat Completions API — отдельного пункта DeepSeek больше нет. Для API, которые возвращают HTTP 400 из-за неподдерживаемых `response_format` или `temperature`, расширение автоматически повторяет запрос без этих необязательных полей. Сам сервис должен поддерживать `messages`, `choices[0].message.content` и доступный с телевизора HTTPS/CORS.

**Запуск перевода:** ARX → «Английские для ИИ» → выбор дорожки → «ИИ-перевод на русский». Субтитры делятся на части до 35 реплик / 3200 символов; проверяется количество строк в ответе, исходные таймкоды сохраняются, виден прогресс. При ошибке исходная дорожка не затирается.

## Конфиденциальность и ограничения

API-ключи хранятся в `Lampa.Storage` на клиентском устройстве и могут быть доступны другим JS-расширениям и механизмам синхронизации. Маскирование текста в настройках не шифрует ключ. Для ИИ рекомендуется отдельный ключ с лимитом расходов. **Весь текст отправленных на перевод субтитров передаётся выбранному ИИ-провайдеру.**

Пользователь самостоятельно выбирает HTTPS-хост. Не вводите ключ от другого сервиса на неизвестном хосте. Не все реализации OpenAI API поддерживают одинаковые параметры и CORS. На физическом Android TV/Tizen/WebOS требуется отдельная проверка.

Устаревшие настройки `ai_key_deepseek` / `ai_model_deepseek`, если они остались после обновления, **не используются новым плагином**; сохранённые значения автоматически не удаляются.

Дополнительно: скорость 0,75×–2×, таймер сна, плавное затухание громкости, сведения о видео и метки на прогресс-баре.
