# ARX Subtitles Server

Независимый backend для Lampa ARX Player Tools: поиск готовых субтитров (Stremio OpenSubtitles v3 + REST OpenSubtitles), скачивание SRT, ИИ-перевод через DeepSeek/OpenRouter, опрос статуса длительной задачи. Backend не связан с сервером OpenSubtitles RU стороннего автора. Node.js 22+, без npm-зависимостей.

## Локальный запуск

```sh
cd arx-subtitles-server
cp .env.example .env
# заполните .env, затем:
set -a; . ./.env; set +a
npm test
npm start
curl http://127.0.0.1:8091/health
```

Для запуска через Docker:

```sh
cd arx-subtitles-server
cp .env.example .env
# впишите свой AI_API_KEY и ARX_CLIENT_TOKEN в .env
docker compose up -d --build
curl http://127.0.0.1:8091/health
```

Сервис по умолчанию доступен на `127.0.0.1:8091` на **сервере**. Для телевизора нужен HTTPS reverse proxy с действующим сертификатом (Caddy, Nginx, Traefik). Не публикуйте сам HTTP-порт наружу. Пример Caddyfile:

```caddyfile
subs.YOUR_DOMAIN.example {
    reverse_proxy 127.0.0.1:8091
}
```

Этот домен — пример: его нужно заменить реальным именем, на которое настроен DNS. Для публичного хоста дополнительно рекомендуется закрыть API ограничениями доступа по сети, в том числе на уровне reverse proxy.

## Ключи и модель

```env
HOST=0.0.0.0
PORT=8091
AI_BASE_URL=https://api.deepseek.com/v1
AI_MODEL=deepseek-chat
AI_API_KEY=YOUR_DEEPSEEK_API_KEY
ARX_CLIENT_TOKEN=RANDOM_MINIMUM_16_CHARACTERS
```

Генерация токена:

```sh
openssl rand -hex 32
```

Токен доступа **не равен** ключу DeepSeek и используется только для авторизации POST-запросов на перевод и GET-запросов на статусы. Он хранится в Lampa Storage на устройстве и будет виден человеку, имеющему доступ к устройству. Не используйте этот токен на недоверенных устройствах. Ключ DeepSeek остаётся только в серверном .env; .env не коммитить в GitHub.

OpenRouter поддерживается через `AI_BASE_URL=https://openrouter.ai/api/v1` и `AI_MODEL=...`, соответствующую модели на OpenRouter.

## Подключение Lampa

Установите `https://arst113.github.io/lampa-watch-resume/arx_player_tools.js`.

В «Настройки → ARX Player Tools» заполните:

1. **URL своего сервера ARX Subtitles** — `https://subs.YOUR_DOMAIN.example`.
2. **Токен доступа к ИИ-переводу** — значение `ARX_CLIENT_TOKEN`, НЕ ключ DeepSeek.
3. При конфликте оставьте «Отключать старый OpenSubtitles RU» включённым.

Во время просмотра открыть **ARX** в штатной панели, затем выбрать «Русские субтитры» или «Английские для ИИ» и конкретный файл. После загрузки английской дорожки выбрать «ИИ-перевод на русский». Продолжение просмотра и пропуск заставок работают отдельно.

Без настроенного backend ARX пытается искать и загружать готовые субтитры напрямую из публичных OpenSubtitles/Stremio, если браузер телевизора позволяет CORS. В этом режиме ИИ-перевод недоступен. Backend решает проблему CORS для готовых субтитров, а также позволяет выполнять AI-запросы без передачи ключа ИИ-провайдера в клиент Lampa.

## HTTP API

- `GET /health` — статус и доступность ИИ.
- `GET /v1/subtitles/search?imdb_id=tt0903747&season=1&episode=1&lang=rus` — объединение двух источников, идентификаторы файлов.
- `GET /v1/subtitles/file/1957291837` — нормализованные SRT cue objects.
- `POST /v1/ai/translate` — тело: `{"from":"en","to":"ru","cues":[{"start":10,"end":12,"text":"Hello"}]}`. Заголовок `X-ARX-Token`.
- `GET /v1/ai/jobs/<job_id>` — процент выполнения, результат или ошибка; заголовок `X-ARX-Token`.

Защита: ограничение тела 1.2 МБ, максимальная длительность и размер текста, лимиты запросов на IP, серверная проверка ID, запрет произвольных URL для скачивания (устойчивость к SSRF), очередь переводов с одним активным заданием, 2 попытки на часть при ошибке модели, 6-часовое время жизни завершённого задания. Кеш частей перевода находится в оперативной памяти и теряется при перезапуске. Длительные незавершённые задания также не переживают перезагрузку сервера.

## Ограничения

- Предложение на GitHub — готовый код, а не развернутый онлайн-сервис. Потребуется запустить Docker на своём VPS и подключить HTTPS-домен. Без `AI_API_KEY` эндпоинт ИИ возвращает ошибку.
- При ручной настройке API в Lampa используйте HTTPS. HTTP допускается только для локальных адресов при разработке.
- Платные вызовы DeepSeek/OpenRouter тарифицируются провайдером. Клиентский токен нужно хранить в тайне; публичный токен может приводить к расходованию средств через чужие запросы.
- Для многочасовых видео обработка может занять несколько минут: текст дробится до 45 реплик / 4200 символов на пакет. Пользователь видит прогресс, а фильм продолжает воспроизводиться.
- Субтитры включаются вручную. Выбор перевода не должен сбивать текущий таймкод видео. Устройство нужно проверить на реальном Android TV и WebOS/Tizen.
- Файлы, возвращаемые сервисом, предназначены для личного просмотра. Учитывайте условия OpenSubtitles и Stremio при публичном распространении или кэшировании субтитров.
